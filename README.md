# 🔗 URL Shortener

A simple and modern URL Shortener built using **Node.js**, **Express.js**, **MongoDB Atlas**, and **Vanilla JavaScript**. It allows users to shorten long URLs, redirect using short links, and track URL statistics.



🔗 [Live Demo](https://url-shortener-t179.onrender.com)

## ✨ Features

- 🔗 Shorten long URLs
- 🚀 Redirect to original URL
- ✏️ Update shortened URLs
- 🗑️ Delete URLs
- 📊 Track access count
- 📱 Responsive UI
- ☁️ MongoDB Atlas Database

## 🛠️ Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## 📦 Installation

```bash
git clone https://github.com/AmishaOnMain/Url-Shortener.git

cd Url-Shortener

npm install

npm run dev
```

Create a `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
BASE_URL=http://localhost:5000
```
